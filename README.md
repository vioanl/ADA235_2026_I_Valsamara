# ΔΥΑΔΙΚΟΤΗΤΑ

Ηλεκτροακουστική σύνθεση σε τρία μέρη για τη δυαδικότητα κύματος–σωματιδίου, γραμμένη σε SuperCollider. Ολόκληρο το έργο βρίσκεται στο αρχείο: `dyadikotita.scd`.

- **Μέρος Α · Η μεταμόρφωση** — ένα ηχητικό αντικείμενο ταξιδεύει από σωματίδιο (αραιές, τυχαίες «ανιχνεύσεις») σε κύμα (συνεχής τόνος με συμβολή), με στάση στον «καθρέφτη» όπου ακούγονται και οι δύο φύσεις. Δύο «ανεπιτήρητες» σιωπές διακόπτουν την πορεία — το αντικείμενο συνεχίζει να αλλάζει μέσα τους.
- **Μέρος Β · Το εργαστήριο** — το πείραμα της διπλής σχισμής: μετρήσεις (κρότοι τέρμα αριστερά ή δεξιά), κροσσοί συμβολής όταν κανείς δεν παρατηρεί, κατάρρευση, και ένα κυματικό «νήμα» που ζαρώνει κάτω από κάθε μέτρηση και ανθίζει στην ελευθερία.
- **Μέρος Γ · Το φάσμα** — ηχοποίηση (sonification) της σειράς Balmer του υδρογόνου: κάθε νότα είναι ένα κβαντικό άλμα n→2, σε Λα μινόρε πεντατονική, με τους πραγματικούς συντελεστές Einstein A ως πιθανότητες. Το έργο τελειώνει με «ιονισμό»: μία μόνη νότα εκτός κλίμακας (747.8 Hz — το όριο Balmer ÷ 2⁴⁰) που δεν προσγειώνεται ποτέ.

## Απαιτήσεις

- **SuperCollider 3.x** — τίποτα άλλο· καμία επιπλέον βιβλιοθήκη ή Quark (χρησιμοποιούνται μόνο UGens της βασικής εγκατάστασης).
- Στερεοφωνική έξοδος. **Συνιστώνται ακουστικά ή ηχεία με χαμηλές συχνότητες:** το τέλος του Α ζει βρίσκεται στην περιοχή 20 Hz και το τέλος του Β στα 40 Hz (σκόπιμα στο όριο του ακουστού, αλλά καλό είναι να ακουστούν).

## Εκτέλεση

1. Ορισμός της επιθυμητής συσκευής εξόδου ως **προεπιλεγμένη του συστήματος πριν** μέσα στο SuperCollider (ο server κλειδώνει στην προεπιλογή κατά το boot).
2. Άνοιγμα του `dyadikotita.scd` στο SuperCollider IDE.
3. Τοποθέτηση κέρσορα οπουδήποτε μέσα στο μεγάλο μπλοκ με τις εξωτερικές παρενθέσεις `( ... )`, **Ctrl+Enter** (Windows/Linux) ή **Cmd+Enter** (macOS).

 Ο server ξεκινά μόνος του (`s.waitForBoot`), φορτώνει τα όργανα και το έργο αρχίζει.
 Στο Post window θα εμφανιστεί «ΔΥΑΔΙΚΟΤΗΤΑ — όργανα έτοιμα» με εκτίμηση διάρκειας, και στη συνέχεια σημείωση για κάθε μέρος και φάση (ΜΕΡΟΣ Α, Β/1: παρατήρηση, Β/2: δύο σχισμές, … Γ/3: αναρρίχηση — ιονισμός, — ΤΕΛΟΣ ΕΡΓΟΥ —).

Διακοπή ανά πάσα στιγμή: Ctrl+. (macOS: Cmd+.)

## Διάρκεια — το κουμπί `~z`

Όλοι οι χρόνοι του έργου κλιμακώνονται αναλογικά από μία μεταβλητή στην κορυφή του αρχείου:

```supercollider
~z = 0.6;   // 0.6 → ~10 λεπτά (προεπιλογή)
            // 1.0 → ~17 λεπτά (long-form εκδοχή)
            // 0.2 → ~3.5 λεπτά (γρήγορη πρόβα της δομής)
```

## Άλλες παράμετροι (προαιρετικές)

Όλες οι αποφάσεις της φόρμας είναι μαζεμένες στην κορυφή του αρχείου, με σχόλια: διάρκειες ανά μέρος/φάση (`~durA`, `~durP1`–`~durP4`, `~durTr`, `~durC`), οι γέφυρες (`~gefAB`, `~gefBC`), το παράθυρο συχνοτήτων του «ανιχνευτή» (`~detLo`/`~detHi`), η τιθάσευση των πιθανοτήτων Einstein στο Γ (`~temper`), και η στάθμη του «εδάφους» 220/220.5 Hz (`~isopedo` — βάλε 0 για γυμνά plucks). Τα δεδομένα του Μέρους Γ (μήκη κύματος και συντελεστές A της σειράς Balmer) βρίσκονται επίσης εκεί, ως πίνακες.

## Τυχαιότητα

Κάθε εκτέλεση διαφέρει ελαφρώς από την προηγούμενη: οι χρονισμοί των «ανιχνεύσεων» ακολουθούν στατιστική Poisson (την ίδια με τα κλικ ενός μετρητή Geiger) και οι μελωδικές επιλογές του Γ κληρώνονται. Αυτό είναι σχεδιαστική επιλογή που πηγάζει από το θέμα του έργου.

## Ηχογράφηση σε αρχείο (προαιρετικά)

```supercollider
s.boot;                      // 1. περίμενε το "server ready" στο Post window
s.recHeaderFormat = "wav";   // 2. (προαιρετικά — αλλιώς γράφει AIFF)
s.record;                    // 3. το Post window δείχνει πού γράφεται το αρχείο
// 4. τρέξε τώρα το μπλοκ του έργου, όπως στις οδηγίες παραπάνω
s.stopRecording;             // 5. όταν δεις "— ΤΕΛΟΣ ΕΡΓΟΥ —"
```


## Πηγές & τεκμηρίωση

- Δεδομένα Μέρους Γ: **NIST Atomic Spectra Database** — Kramida, Ralchenko, Reader & NIST ASD Team (υδρογόνο, σειρά Balmer: μήκη κύματος, συντελεστές Einstein A).
- Το έργο δημιουργήθηκε σε διάλογο με το **Claude (Anthropic)**. Η πλήρης τεκμηρίωση της διαδικασίας βρίσκεται στον φάκελο `queries/` του αποθετηρίου, και το σκεπτικό στην `ΠεριγραφήΕργασίας.md`.
